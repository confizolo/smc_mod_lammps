# Test Files

This directory contains two example of LAMMPS run files. 

1. ``bridging.lammps`` run extrusion on a solution of 2 10-bead long linear polymers with two patches per polymer implementing bond-driven bridging interactions by creating and removing bonds based on the distance.
2. ``extrusion.lammps`` run extrusion on a solution of 2 10-bead long linear polymers with two patches per polymer with bridging implemented through "patchy beads" interacting through a morse potential.
